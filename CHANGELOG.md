# Changelog

## 0.1.0 - 2026-06-02

LoreDock first MVP release.

- Added local-first VS Code extension scaffold for long-form fiction projects.
- Added LoreDock Activity Bar with manuscript, codex, and AI status views.
- Added project initialization, volume/chapter management, writing statistics, and manuscript import/export.
- Added codex cards for characters, locations, world rules, foreshadowing, timeline events, scenes, and beats.
- Added AI settings webview, provider/key configuration, model selection, diagnostics, and request preflight.
- Added AI workflows for continuation, polishing, chapter summaries, consistency checks, and confirmation before applying edits.
- Added local history records and git-ignore protections for project data, secrets, manuscript content, and generated VSIX files.
