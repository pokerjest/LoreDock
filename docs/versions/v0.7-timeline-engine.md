# v0.7 Timeline Engine

## 目标

加入受 Aeon Timeline、Campfire、World Anvil 和 Plottr 启发的时间线能力。它要追踪故事时间、叙事顺序、人物、地点和因果关系。

## 实现

- 增加 `timelines/` 目录。
- 时间线事件作为 story element。
- 事件字段：
  - title
  - timelineId
  - storyTime
  - narrativeOrder
  - duration
  - locationRefs
  - participantRefs
  - causeRefs
  - consequenceRefs
  - chapterRefs
  - sceneRefs
  - status
- 时间线视图支持列表模式和 lane 模式。
- 事件可以绑定人物、地点、势力、章节和场景。
- 检查：
  - 同一人物同一时间出现在多个地点
  - 事件发生在它声明的原因之前
  - 缺失地点
  - 缺失参与者
  - 时长未解决

## 优化

- 区分故事发生顺序和手稿叙事顺序。
- 支持模糊时间标签，不强迫用户一开始就使用真实日历。
- 允许项目早期保持模糊，后期再精确。
- 时间线检查只给 warning，不阻塞写作。

## 打磨

- 时间线设置向导提供简单模式：
  - 模糊顺序
  - 自定义历法
  - 真实日期
- 支持从章节或场景创建事件。
- 按人物、地点、势力、剧情线和状态过滤。
- 冲突报告要人能读懂。

## 验收标准

- 用户可以独立于章节顺序追踪事件。
- 事件引用会出现在人物和地点的反链中。
- 基础连续性冲突能被检测。
- 测试覆盖事件排序、引用解析和冲突检测。

## 风险

- 太早强迫作者精确时间。
- 在事件身份稳定前做复杂日历引擎。
- 时间线 UI 反客为主，压过写作流。
