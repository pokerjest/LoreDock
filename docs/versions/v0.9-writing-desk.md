# v0.9 Writing Desk

## 目标

围绕当前章节创建一个舒服的写作驾驶舱。作者应该能在不离开编辑器的情况下看到相关上下文。

## 实现

- Writing Desk 侧边面板。
- 当前章节上下文：
  - 章节状态
  - 字数
  - 今日进度
  - 关联场景
  - 相关人物
  - 相关地点
  - 相关规则
  - 时间线事件
  - 上一章摘要，如果存在
- 快捷动作：
  - 打开相关卡片
  - 创建笔记
  - 创建场景
  - 标记章节状态
  - 运行当前章节检查
- Focus mode 命令，隐藏非必要 LoreDock 面板。
- Story Notes 侧栏。

## 优化

- 根据当前 editor 文件快速解析上下文。
- 上下文刷新不能阻塞打字。
- 缓存 context projection。
- 侧栏动作要小而可预测。

## 打磨

- UI 安静、密集，适合反复使用。
- 主面板里不要放教程式说明文字。
- 没有上下文时提供有用空状态。
- 常用动作提供快捷键。

## 验收标准

- 打开章节时 Writing Desk 上下文会更新。
- 相关故事元素足够准确，值得信任。
- 面板能提高写作速度，而不是打断写作。
- 测试覆盖上下文解析和命令动作。

## 风险

- Writing Desk 变成塞满组件的仪表盘。
- 打字时刷新卡顿。
- 把推测上下文显示成已确认事实。
