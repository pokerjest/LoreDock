# v0.5 Knowledge Graph

## 目标

加入 Obsidian 和 Novelcrafter 风格的故事知识系统：提及、反链、未链接引用和本地图谱。

## 实现

- 在 `.loredock/indexes/references.json` 下保存引用索引。
- 通过 v0.1 `ManuscriptReader` 扫描章节；不直接读取 Manuscript 私有 manifest，不改写章节正文。
- 扫描以下文件中的名称和别名：
  - 章节
  - 场景卡
  - 大纲文件
  - 故事圣经文件
- 每个故事元素显示反向链接。
- 支持未链接提及建议。
- 局部图谱可以围绕以下对象展开：
  - 当前章节
  - 当前故事元素
  - 选中的人物或地点
- 引用详情视图显示 excerpt。

## 优化

- 根据文件修改时间做增量索引。
- 避免每次插件激活都扫描大型项目。
- 统一别名规范化逻辑。
- 中文匹配不能依赖英文 word boundary。

## 打磨

- 明确区分已确认链接和建议提及。
- 支持 false positive ignore-list。
- 快捷动作：打开来源、打开目标、忽略提及。
- 小项目里的图谱也要有用。

## 验收标准

- 人物卡能显示该人物在哪些章节出现。
- 未链接提及能帮助发现遗漏引用。
- 重建索引结果确定。
- 损坏文件会被报告，但不会阻止整个扫描。
- 测试覆盖别名匹配、忽略词、excerpt 和增量重建。

## 风险

- false positive 太多，损害用户信任。
- 图谱视觉上很酷但实际没用。
- 把建议提及误当成已确认链接。
