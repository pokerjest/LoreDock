# v0.8 Consistency Lab

## 目标

用确定性检查把 LoreDock 变成长篇连续性助手。它应该发现可能的问题，但永远不能自动改写正文。

## 实现

- 增加 Consistency Lab capability。
- 健康报告类型：
  - structure
  - references
  - timeline
  - story bible
  - progressions
  - foreshadowing
- 确定性检查：
  - 缺失章节文件
  - orphan manuscript 文件
  - 损坏 frontmatter
  - 重复 ID
  - 引用不存在的故事元素
  - 孤立故事元素
  - 时间线冲突
  - 规则提及和疑似违反
  - 人物状态 progression 冲突
- 报告输出为 Markdown。
- 只对简单问题提供安全修复预览。

## 优化

- 每个 issue 都有稳定 fingerprint。
- 支持 baseline ignore list。
- 区分严重错误和写作建议。
- 每个检查都必须解释得清楚。

## 打磨

- 一个命令跑全项目健康检查。
- 一个命令跑当前章节健康检查。
- 报告中链接到来源文件。
- 修复预览显示具体会改哪些文件。
- 对刻意保持模糊的项目不要噪音过大。

## 验收标准

- 不使用 AI 也能生成项目健康报告。
- 报告生成不会修改任何文件。
- 安全修复必须显式确认。
- 已忽略问题通过稳定 fingerprint 保持忽略。
- 测试覆盖每类确定性检查和 baseline 行为。

## 风险

- 用简单启发式过度宣称语义正确性。
- 报告太吵。
- 自动修复触碰手稿正文。
