# v1.1 Compile

## 目标

加入受 Scrivener Compile 和 Atticus 启发的强导出与排版流水线。这个版本帮助作者把本地草稿变成可分享、可投稿、可发布的稿件。

## 实现

- Compile profiles。
- 通过 v0.1 `ManuscriptReader` 的稳定书、卷、章顺序组稿；Compile 不直接修改手稿文件。
- 导出格式：
  - Markdown
  - TXT
  - DOCX
  - EPUB
  - PDF
- 导出选项：
  - 标题页
  - 作者
  - 是否包含卷标题
  - 章节编号
  - 前言材料
  - 后记材料
  - 字体
  - 字号
  - 行距
  - 段落间距
- 编译预览。
- 导出日志。
- 导出前创建快照。

## 优化

- 分离 book assembly 和 format rendering。
- Markdown/TXT 导出器先保持简单稳定。
- 如果高级格式依赖较重，作为可选导出器。
- 写出后验证输出文件。

## 打磨

- 预设 profile：
  - 草稿
  - 投稿
  - 电子书
  - 纸书校样
- 清晰显示导出目标路径。
- 对不支持的格式化选项给出友好错误。
- 文档包含截图或示例输出。

## 验收标准

- 导出严格遵守书、卷、章顺序。
- Markdown 和 TXT 永远可用。
- DOCX、EPUB、PDF 足够用于实际审阅。
- 导出不修改手稿文件。
- 测试覆盖组稿顺序、profile 解析和每个 renderer。

## 风险

- 过早追求完美出版排版。
- Compile model 稳定前引入大型依赖。
- 把 PDF 输出误当成专业排版系统。
