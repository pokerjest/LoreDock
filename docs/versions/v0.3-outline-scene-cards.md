# v0.3 Outline and Scene Cards

## 目标

通过大纲和场景卡把规划能力接入项目。这个版本吸收 Scrivener、Plottr、Dabble 和 Manuskript 的结构规划能力，但不做重型视觉画布。

## 实现

- 增加 `outlines/`，存放人可读的大纲 Markdown。
- 大纲解析规则：
  - `#` 表示卷或大段落
  - `##` 表示章节
  - `###` 表示场景
  - `-` 表示 Beat 或备注
- 导入大纲命令必须 preview first。
- 用户确认后，才通过 v0.1 `ManuscriptActions` 从大纲生成手稿结构；Outline 不能直接写 `manuscript/manifest.json`。
- 场景卡使用 Markdown + frontmatter。
- 场景卡字段：
  - title
  - chapterId
  - order
  - pov
  - locationRefs
  - characterRefs
  - conflict
  - turn
  - outcome
  - status
- 增加 Outline 树或 Outline 视图。
- 章节、大纲条目和场景卡之间可以互相跳转。
- 场景卡使用 v0.1 `chapterId` 绑定章节，不能依赖可变章节标题。

## 优化

- 大纲解析宽容但确定。
- 保留原始大纲文本。
- 大纲导入尽可能支持幂等。
- 除非用户确认生成，否则不能修改 manuscript。

## 打磨

- 预览文档明确列出会创建什么。
- 取消导入不会留下半成品文件。
- 场景卡模板保持短小实用。
- 树图标区分卷、章、场景和 Beat。

## 验收标准

- Markdown 大纲可以在显式确认后生成手稿结构。
- 用户不使用视觉板，也能维护场景。
- 场景卡可以引用 v0.2 创建的人物和地点。
- 测试覆盖大纲解析、预览生成、确认导入和取消导入。

## 风险

- 场景卡字段过多。
- 大纲导入和手稿生成的关系不清楚。
- 在场景身份稳定前开始做 Plot Grid。
