# v1.5 Template Packs

## 目标

让 LoreDock 拥有强扩展性，但不依赖云端市场。用户应该能本地添加题材 schema、写作方法和项目模板。

## 实现

- 本地 template pack 格式。
- Pack 类型：
  - project template
  - story element schema pack
  - scene card template
  - plot grid template
  - timeline template
  - export profile pack
  - writing method pack
- 内置写作方法包：
  - 三幕式
  - 英雄旅程
  - 雪花法
  - Save the Cat 风格节拍
  - 网文卷章工作流
- 内置题材包：
  - 奇幻
  - 科幻
  - 悬疑
  - 都市奇幻
  - 群像剧
- 支持导入、检查、启用、禁用和复制 pack。

## 优化

- Pack 格式保持声明式。
- 启用前先验证 pack。
- 永远不允许 pack 执行任意代码。
- 用户可以把 pack 复制到项目中自行修改。

## 打磨

- Pack 浏览器。
- 预览 pack 会添加什么。
- 明确兼容版本。
- 提供高质量 starter templates。
- 文档说明如何编写本地 pack。

## 验收标准

- 项目启用 pack 后能获得新的模板或 schema。
- 禁用 pack 不删除用户已创建内容。
- 无效 pack 安全失败并产生诊断。
- 测试覆盖 pack 验证、启用/禁用和模板生成。

## 风险

- 不小心做成有安全风险的插件运行时。
- 内置 pack 太多导致质量下降。
- 多个 pack 之间 schema 冲突。
