# v0.4 Plot Grid

## 目标

加入第一个结构化视觉工作台：剧情矩阵。它用于同时查看故事线、人物弧、地点和章节进度。

## 实现

- 使用轻量 webview 实现 Plot Grid。
- 行可以是章节或场景。
- 章节行只从 v0.1 `ManuscriptReader` 和场景卡 projection 读取；Plot Grid 不拥有章节顺序 canon。
- 列是可配置故事轨道：
  - 主线剧情
  - 人物弧
  - 地点
  - 世界规则备注
  - 状态
  - 字数
- 增加 plotline 类型故事元素。
- 支持按以下条件过滤章节和场景：
  - 人物
  - 地点
  - 剧情线
  - 状态
- 从矩阵单元格打开对应章节、场景卡或故事元素。
- 在安全时支持拖动调整同一章节内的场景顺序。

## 优化

- 从紧凑 projection model 加载矩阵数据，不在每次渲染时重新解析所有文件。
- webview 状态必须可序列化。
- message passing 使用明确 action type。
- 拖拽调整必须有预览或撤销边界。

## 打磨

- 布局要紧凑、可扫读。
- 长篇项目中表头保持可见。
- 空状态引导用户创建大纲或场景。
- 尽可能支持键盘导航。
- 避免为了好看牺牲信息密度。

## 验收标准

- 用户能在一个视图里看到章节、场景、剧情线、人物和地点结构。
- 点击任何链接项都能打开源文件。
- 调整顺序不会破坏章节或场景 order。
- 测试覆盖 projection 生成和 webview action 处理。

## 风险

- 第一个 webview 变成第二个应用。
- 在 undo/preview 不成熟时过度依赖拖拽。
- 底层数据模型不稳时先做复杂 UI。
